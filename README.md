# ApexBiz Enterprise Platform

ApexBiz is a beginner-to-enterprise full-stack software project built with NestJS, TypeScript, React, Tailwind CSS, PostgreSQL, Docker, CI/CD, and Google Cloud.

## Planned Features

- JWT username/password authentication
- RBAC with Admin, Manager, and Cashier roles
- Business management
- Branch management
- Wallet system
- Double-entry ledger
- Transactions
- POS system
- Inventory management
- React admin dashboard
- Docker and Docker Compose
- CI/CD using GitHub Actions
- Google Cloud deployment
- Kubernetes, Helm, Skaffold
- Grafana monitoring
